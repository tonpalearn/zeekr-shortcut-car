## 1. เป้าหมาย

ต้นคุยกับ Claude ได้จากจอกลางของ Zeekr 7X โดย**ไม่ต้องละมือจากพวงมาลัย**: กดปุ่ม → พูด → Claude ตอบเป็นเสียง
(+ ข้อความสั้นบนจอ) — ใช้คนเดียว เน้นสะดวกก่อน

## 3. ขอบเขตแต่ละเฟส

### เฟส 1 — คุยด้วยเสียง (MVP)
- คำสั่งใหม่ **"ถาม Claude"** ผูกกับปุ่มพวงมาลัย/สติกเกอร์ได้ + การ์ดบนหน้าหลัก
- กด → ฟังเสียง → แปลงเป็นข้อความ → ส่ง Claude → ตอบเป็นเสียง + ข้อความในหน้าต่างลอย
- จำบทสนทนาในรอบนั้นได้ (กดถามต่อได้) · ล้างเมื่อปิดหน้าต่าง
- ตอนจอด (เกียร์ P): พิมพ์ถามด้วยแป้นได้ อ่านคำตอบยาวได้
- หน้าตั้งค่า: ใส่กุญแจ Claude API · เลือกรุ่น (ค่าเริ่ม `claude-sonnet-5-5` · เร็ว/ถูกกว่า `claude-haiku-5-5`) · ภาษาคำตอบ

### เฟส 1.1 — ทางเลือกใช้บัญชี subscription (ต้นเคาะ 21 พ.ย. 2569)
- Anthropic ไม่เปิดให้แอปอื่นล็อกอินด้วยบัญชี Pro/Max แทนกุญแจ API → ทางที่ถูกต้องคือ **เปิดแอป Claude ทางการ** (`com.anthropic.claude`) ที่ติดตั้งบนจอรถ
- ตั้งค่า → สวิตช์ “ปุ่ม ถาม Claude เปิดแอป Claude ทางการ” · ปุ่มลัดจะเปิดแอปนั้นแทน (แอปเราไม่แตะบัญชี/token)
- หน้า Claude มีปุ่ม “เปิดแอป Claude” เมื่อพบแอป · ตั้งไว้แต่ไม่พบแอป → เปิดหน้าในแอปพร้อมบอกเหตุผล
- ยังไม่รู้: แอป Claude ทางการลง/ล็อกอินบนจอรถได้ไหม (จออาจไม่มีบริการของ Google) → เช็กด้วยปุ่ม ✓

### เฟส 2 — Claude รู้สภาพรถ + สั่งรถได้ (ต้นสั่งเริ่ม 21 พ.ย. 2569 · ใช้ค่าแนะนำ)
**อ่าน:** ทุกคำถามแนบ "สภาพรถตอนนี้" ไปกับ system prompt — สัญญาณที่ dts88 ยืนยันแล้ว (CONFIRMED/PROVISIONAL) ที่มีค่า
เช่น ความเร็ว เกียร์ แบต ระยะวิ่ง อุณหภูมิ ประตู เข็มขัด ไฟ โหมดเฝ้ารถ (อ่านผ่าน `Telemetry.readings()`)

**สั่ง:** เครื่องมือ `car_action` (Claude tool use) เรียกคำสั่งจาก `ButtonAction` ได้**เฉพาะรายการอนุญาต** 3 ระดับ (บังคับด้วยโค้ด `ClaudeCarPolicy`):

| ระดับ | คำสั่ง | กติกา |
|---|---|---|
| ทำทันที | โหมดขับ · แอร์ (เปิดปิด ขึ้นลงทีละขั้น หมุนเวียน ไล่ฝ้า) · อุ่น/ระบาย/นวดเบาะ · อุ่นพวงมาลัย · เพลง/เสียง · น้ำหอม · กล้อง 360 · ไฟต้อนรับ/ไฟชาร์จ · ถ่ายรูป · ล็อกคลิปเหตุการณ์ | ทำเลย แล้วบอกผลจริงจากรถ (สำเร็จ/ไม่เปลี่ยน/ทำไม่ได้) |
| ต้องกดยืนยันบนจอ + จอดเท่านั้น | ล็อกรถ · โหมดเฝ้ารถ · แคมปิ้ง · โรงหนัง · คืนตำแหน่งเบาะ · ปิดประตู/ฝาท้าย · พับกระจก · ฝาช่องชาร์จ | รถวิ่ง → ปฏิเสธ · จอด → ขึ้นการ์ด "ยืนยัน/ยกเลิก" บนจอ Claude ไม่มีทางกดแทน |
| ห้าม | ทุกอย่างที่ไม่อยู่ในรายการ (เช่น ไฟขับขี่ ไฟตัดหมอก เปลี่ยนเกียร์เสียง ผู้ช่วยเสียงของรถ) | ไม่ส่งให้ Claude เห็นเลย |

- ทำเฉพาะเมื่อผู้ใช้ขอชัด ๆ · ทีละขั้นได้สูงสุด 5 ขั้นต่อครั้ง · ทุกคำสั่งลงกล่องดำของแอปเป็น `claude:<คำสั่ง>`
- ตั้งค่า → สวิตช์ "ให้ Claude สั่งรถได้" (ค่าเริ่มต้นเปิด) ปิดแล้วเหลืออ่านอย่างเดียว
- ข้อจำกัด: ตั้งอุณหภูมิเป็นตัวเลขตรง ๆ ไม่ได้ (รถรับแค่ขึ้น/ลงทีละขั้น และยังอ่านค่าที่ตั้งไม่ได้) · ไม่มีคำสั่งปลดล็อก/เปิดประตู

**Done เฟส 2:** สั่ง "เปิดแอร์" ด้วยเสียงแล้วแอร์เปิดจริง + Claude บอกผลจริง · สั่งปิดประตูตอนวิ่ง → ปฏิเสธ · ตอนจอด → ต้องกดยืนยันก่อน · ปิดสวิตช์แล้ว Claude สั่งรถไม่ได้

### เฟส 3 — (ไอเดีย ยังไม่ผูกมัด)
- ต่อปฏิทิน/LINE/ข้อมูลส่วนตัวผ่าน MCP · persona ของต้น

### ไม่ทำ (non-goals)
- ไม่แทนผู้ช่วยเสียงของรถ · ไม่ทำ AI ออฟไลน์ · ไม่แจกให้คนอื่นใช้ (ใช้เองคนเดียว)

## 4. กติกาความปลอดภัย (บังคับด้วยโค้ด)
- รถวิ่ง (ความเร็ว > 0): ตอบเสียงเท่านั้น สั้น ≤ 2–3 ประโยค · บนจอโชว์แค่บรรทัดเดียว · ปิดแป้นพิมพ์
- ทุกคำสั่งที่แตะรถในเฟส 2 ต้องผ่านรายการอนุญาต + บันทึกลงไฟล์ log
- กุญแจ API เก็บแบบเข้ารหัสในเครื่อง · **ไม่ถูกสำรองลง USB** · ไม่อยู่ใน repo

## 5. สิ่งที่ยังไม่รู้ — ต้องลองบนรถจริงก่อน (สำคัญ)
| เรื่อง | ทำไมสำคัญ | ทางสำรอง |
|---|---|---|
| จอรถมีระบบแปลงเสียงเป็นข้อความ (Android SpeechRecognizer) ไหม | Claude API รับเสียงตรง ๆ ไม่ได้ ต้องแปลงก่อน | ส่งเสียงไปบริการแปลงเสียงบนคลาวด์ (มีค่าใช้จ่าย + ต้องมีกุญแจอีกตัว) |
